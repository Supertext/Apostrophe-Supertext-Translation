# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues, pull requests or discussions. Report them privately instead:

- **Preferred:** [report a vulnerability](https://github.com/Supertext/Apostrophe-Supertext-Translation/security/advisories/new) through GitHub's private vulnerability reporting.
- **Or by email:** support@supertext.com, with "Security" in the subject.

Please include what you found, the steps to reproduce it, the affected version and the impact you see. We'll confirm that we received it, keep you posted while we work on a fix and credit you in the release notes if you like.

## Supported versions

Security fixes go into the latest release and `main`. Please check that the problem still exists there before reporting.

This policy covers the code in this repository. For the Supertext service itself (supertext.com, the Supertext API), use the same contacts.
